Cover Story

Whatever you type on this page goes into a hidden buffer. The screen shows a document being written instead. Nothing you type leaves this page: there is no server, no account and no analytics, and the page never sends what you type anywhere.

  1. Peek. Hold Ctrl for about a second to see what you actually wrote. Let go to hide it again.
  2. Copy. While peeking, press Ctrl + C to copy your real text to the clipboard.
  3. Clear. Press Esc to erase the hidden text and the screen. The page also clears itself after 10 minutes in a background tab.
  4. Save and open. Save downloads your text as a .cover file encrypted with AES-256-GCM, the key derived from your password with PBKDF2 (SHA-256, 310,000 rounds). Open restores it and replaces what is on the page. There is no way to recover a forgotten password.

Reloading or closing the tab erases the hidden text. Save first if you need it. The screen shows a story, not your words, so the word count in the header counts the story.

Stored only in this browser (localStorage). Leave it blank to use the built-in story.
